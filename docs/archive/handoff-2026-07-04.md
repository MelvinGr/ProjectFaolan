## Decodes worth remembering

- **Pre-IIR spawn frame `@135` island = `[archetype][class]`** — the ONLY genuine per-character field in the
  whole frame; everything else is the RDB script-engine char buffer (transient, 0 for a player) or the
  `0xB7` `EntryTableX` constant. `FrameArchetype(class)` numbering is Soldier=1/Priest=2/Rogue=3/Mage=4 (NOT
  the `ArchType` enum order). `FreshPreFrame` used to hardcode Barbarian for everyone — fixed.
- **NpcSpell effect payload (54 bytes, byte-packed BE)**: `@10` u16 Duration (= `Spell.DurationMs/10`),
  `@13/@17/@33` flags (0/1, 1/2, 0/1 — semantics TBD), `@23` u32 spell id (== `SpellId` = `Spell.Id << 8 |
  rank`), `@29` Magnitude, `@45` Rank (equal on most = rank), `@50` u32 an unvalidated per-cast counter
  (dropped, 0 when synthesised). `NpcSpellEffectCodec` round-trips all 21 goldens byte-exact.
- **`Spell.Id` is the BASE id**; wire/NpcSpell/payload ids are `(Spell.Id << 8) | rank`.

## Gotchas / notes

- **Kill the server before committing `faolan.db`** — a `git checkout -- faolan.db` under a running server
  makes its connection readonly. (`git add`/commit while running is fine.) Migrations apply at startup via
  `DatabaseMigrator`, or `dotnet ef database update --connection "Data Source=$PWD/faolan.db"`.
- Tests flake occasionally with a single failure during a migration/re-import (DB contention) — re-run; it's
  green.
